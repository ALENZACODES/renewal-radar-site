# Renewal Radar – Project Page

This is the one-page website for Renewal Radar, a project about Canadian mortgage renewals. The page explains what the project does, why renewals matter, who it is for, and how it works.

Live site: https://renewal-radar-site.vercel.app

Built with [v0 by Vercel](https://v0.app), then reviewed and published to GitHub.

## Run it locally

You need Node.js 20 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

To make a production build:

```bash
pnpm build
pnpm start
```

## Stack

- Next.js (App Router) and React
- TypeScript
- Tailwind CSS v4
- shadcn/ui components on Base UI
- lucide-react icons
- Vercel Analytics, hosted on Vercel
